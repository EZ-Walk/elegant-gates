# Error Documentation

This directory contains documentation for common errors encountered during VHF14 setup and operation.

## Available Error Documents

- [**mapbox-token-build-error.md**](mapbox-token-build-error.md) - Map frontend loads but displays blank map due to missing Mapbox token during build process

## Contributing

When documenting new errors, please include:

1. **Problem description** - Clear symptoms and user impact
2. **Root cause** - Technical explanation of why the error occurs  
3. **Step-by-step solution** - Exact commands and configuration changes needed
4. **Verification steps** - How to confirm the fix worked
5. **Prevention strategies** - How to avoid the issue in the future

## Error Report Template

```markdown
# Error Title

## Problem
Brief description of the issue and symptoms.

## Root Cause
Technical explanation of why this happens.

## Solution
Step-by-step fix with code examples.

## Verification
How to confirm the fix worked.

## Prevention
How to avoid this in the future.

## Date
YYYY-MM-DD

## Contributors
Who diagnosed/fixed this issue.
```
